第一部分（给人看）

要回答什么

  1. 该按的时候，模型想按吗？看正确决策窗口里的下压概率。
  2. 真正按的时候，模型靠什么？看实际下压那次推理里，各 token 和各层的影响。

全程不换输入，不换 motion，不换 context，不做遮挡和 patch。结果只说明相关，因果留给下一阶段。

两个决策点怎么算

决策点算法
正确决策窗口 A① 用官方环境和本局 seed 逐步仿真，记录第 N 次经过时方块距目标不超过 0.06 m 的步数区间。② 减去下压耗时（从开始下压到按钮按下，取同速度成功局的中位数）。③ 这段区间覆盖到的推理就是 A（每 16 步一次推理）。
实际决策点 B第一个真实执行时开始持续下压的动作 chunk 所对应的推理。下压由 TCP 高度判定：chunk 前 16 行的最低高度比悬停高度低 2 cm 以上，这个阈值用真实下压片段校准。

二 任务事实（窗口计算的依据）

  • 官方 StopCube.py：每程 M∈{60,80,120}，次数 N∈{2..5}，方块沿 0.6 m 直线往返，目标在中点；理论应按时刻 T=M(N-1/2)。
  • is_obj_stopped_onto：方块中心距目标 ≤ 3×0.02=0.06 m 才算停在目标上，理论窗口约 T ± M/10。
  • evaluate：按下时不在目标区立刻失败；超过 M·N 步未按也失败；停止时刻必须落在第 N 程。
  • 评估用任务代码以 third_party/robomme_benchmark 锁定 commit（856bc3a）为准，官方 main 只是参考，实施时核对。

四 机制细节

4.1 下压判定

hover_z  = 本局 B 之前连续静止段的 state_z 中位数
is_press = min(action_z[:16]) < hover_z - 0.02     # 单位 m
t_onset  = 第一个真实执行且满足条件的行对应的步数
B        = t_onset 所在 chunk 的 infer_seq
L        = a - t_onset                              # a 为本局结束步数；用录像核对

0.02 m 是起始值，第 1 轮用真实下压片段校准，改动写入留档。

4.2 窗口 A

L_M = 同速度 M 的成功局 L 的中位数
A_step_range = [visit_in - L_M, visit_out - L_M]
A = 与该区间有重叠的全部 chunk 的 infer_seq

4.3 深度推理集合

deep_set = {A 的每次推理 ±3} ∪ {B ±3}
上限估算：按时局约 7 次 × 21 + 其他局约 14 次 × 29 ≈ 553 次

4.4 下压概率

用独立 RNG（fold_in(固定种子, episode, infer_seq, i)）生成 32 份噪声，调用不带捕获的采样函数，结果只写盘不返回。TCP 高度由 official-sim 解释器离线算。真实下压的那一份不计入 32 次，另行记录。

4.5 下压方向 d

d_ep = mean(x_0 @ B 的 32 次, 前 16 行) - mean(x_0 @ B-1 的 32 次, 前 16 行)
在归一化动作空间取单位向量，每局一个

4.6 信息流量

主干 kv 头数为 1，V[l] 形状为 (b, P, 1, H)，所以每层每 token 一个范数，8 个头共用。flow[step,l,h,q,key] = probs_action[...] × ‖V[l][key]‖，实施时先核对形状。只汇总前 16 个动作 query，并报告相对均匀分配的比值。

4.7 梯度归因

对 prefix 嵌入 pt（进入第 0 层前）求导
目标 J_step = ⟨v_t, d_ep⟩，v_t 只取前 16 行，x_t 做 stop_gradient
每步单独反向，不穿过整条去噪轨迹
每个决策点：4 个噪声 × 10 步
输出每 token 的 ‖g‖ 和 g·pt

点位只取 B、B-1、A，局数和点位最多 50 × 3。不用积分梯度，因为它要构造人工基线。

4.8 逐层投影

每次循环内，第 l 层后的 hs_l:
v_l = action_out_proj(final_norm_1(hs_l, ad))[-AH:]
lens[step, l] = ⟨v_l 前 16 行, d_ep⟩ / ‖v_17 前 16 行‖

对照：10 个随机单位方向；同局悬停段推理。输出层只为最后一层训练，前面层读数可能不可靠；如曲线不可靠，再为每层训练线性读出，这项不算默认工作。

4.9 线性探针

  • 样本：深度集合内的推理，隐状态取各层帧记忆、motion、动作 token 的分组平均。
  • 目标：现在该不该按（是否在 A 内）、已经过次数、距应按时刻的步数。
  • 防错：按局做 5 折；按局打乱标签作对照；同位置「只用当前图像 token」作对照；局级 bootstrap 给区间。
  • 限制：样本只在决策点附近，次数和时间高度相关。结论只写「可解码」，不写「模型使用了」。

4.10 深度 npz 键

键形状说明
noise_actions(32, 20, 8) f3232 次采样
value_norm(18, P) f32每层 token 的 value 范数
hidden_prefix(18, P, 2048) f16prefill 隐状态，约 87 MB，冒烟核对
hidden_action(10, 18, 20, 1024) f16动作 token 隐状态
lens(10, 18) f32逐层投影；需要 d_ep，第 3 遍计算
grad_norm、grad_dot(4, 10, P) f32仅 B、B-1、A

d_ep 要等第 2 轮采样后才有，所以梯度和逐层投影分两遍：第 2 轮先得采样和隐状态，第 3 遍按 d_ep 重放到同一推理计算。重放同样要满足动作逐位一致。

九 盲区诚实清单

  • 没有基线模型对照；基线要另开计划。
