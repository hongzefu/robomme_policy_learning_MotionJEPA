二 任务事实（窗口计算的依据）

  • 官方 StopCube.py：每程 M∈{60,80,120}，次数 N∈{2..5}，方块沿 0.6 m 直线往返，目标在中点；理论应按时刻 T=M(N-1/2)。
  • is_obj_stopped_onto：方块水平距目标 ≤ 3×cube_half_size 才算停在目标上。move_straight_line 使用 smoothstep，原 T ± M/10 是线性近似，不用于实际窗口；本轮从同 seed 仿真的真实位置和官方阈值取区间。
  • evaluate：按下时不在目标区立刻失败；超过 M·N 步未按也失败；停止时刻必须落在第 N 程。
  • 评估用任务代码以 third_party/robomme_benchmark 锁定 commit 856bc3a189d4172f3f47dbee4424d585f8d78db3 为准，不读取移动的上游版本作为运行代码。
  • StopCube.step 先读按钮锁存，再调用父类步进，最后移动方块；is_obj_stopped_onto 在物体位于目标且已停时记录 stop_timestep。按钮物理触发、停步与终局不能混为同一个时刻，需保留步进前后状态。
  • EpisodeEvaluator.get_action_chunk 返回每次预测的前 16 行，逐行执行；末尾 chunk 可因终局截断，不能把未执行行算入实际下压。

四 机制细节

4.1 独立悬停参考与实际下压

hover_z = 任务按钮悬停定义与成功示范确认的 TCP 参考高度
predicted_press = min(target_tcp_z[:实际可执行行数]) < hover_z - delta_z
command_press_step = 首条实际送入环境且满足预测下压判据的动作步
actual_press_onset = 实际 TCP 首次跨过同一高度阈值的环境步，另行保存
press_infer = 产生首条实际执行下压命令的 infer_seq
button_trigger_step = 逐步记录中按钮首次触发的步
motion_delay = button_trigger_step - command_press_step

delta_z 初值 0.02 m，须在示范与单局实跑中校准，人工确认前保留证据与原值。悬停参考不依赖是否存在 press_infer。未按、首次推理即下压、未观察到悬停、没有同速度成功示范均显式记录；来源不足时不能编造参考。逐步真实记录为实际运动证据，目标姿态换算仅用于预测动作分类。提前量从命令实际发出算到按钮触发，包含伺服响应及后续运动；不能只扣除 TCP 已跨阈值之后的剩余时间。

start_range = [target_visit_in - motion_delay, target_visit_out - motion_delay]
window_infers = 与 start_range 重叠且真实存在的全部推理
window_rep = window_infers 中最接近 start_range 中心的推理
            同距取较早者；空集合记录不可观测

耗时校准按起始姿态和数据来源核对，报告逐样本分布；使用中位数时列明样本集合和覆盖的速度/姿态，不暗中跨不适用姿态外推。成功局须核对按钮触发、官方停步与物体在目标的位置；终局步数不作为耗时端点。

4.3 悬停延长、恢复与深度推理集合

正常运行提前按错后，在独立延长运行中重放到已确认悬停段的末端、且早于首次下压命令。悬停命令 hold_qpos 的前 7 维取该行实测关节位置，末维复用该行 executed_action[7] 保持夹爪控制目标；原始 8 维状态另行保留，不能把手指物理位置米直接作为开合命令。接管期间每一步执行该命令，模型推理、真实画面、状态和记忆照常更新。恢复步取 start_range 中心附近、现有 16 步推理合同允许的最近一次新推理边界，同距取较早者，且必须晚于接管步；在该边界完成真实历史续包后执行新推理的动作，不恢复接管期间积压的旧动作。不修改续包长度或生产 RPC 合同，不重复帧、漏帧或使用旧记忆凑齐输入。第一阶段确认页显示理想恢复步、实际恢复步及偏差、悬停位置、提前量和两种动作。

deep_set = union(window_infers 每项前后 3 次推理, press_infer 前后 3 次推理)
deep_set = deep_set 与该轨迹已有 infer_seq 集合的交集
gradient_set = unique(window_rep, press_infer, press_infer - 1)
gradient_set 仅保留真实存在且具备下压方向的点
轨迹身份 = episode_key + trajectory_kind(normal/hold_extended)

正常轨迹缺少正确时机时保持缺失；延长轨迹只为对应干预条件提供观测，不回填成原正常轨迹。没有安全悬停段或无法校准恢复步时报告具体局与证据，不能自行执行其他替代动作。第一次生成的接管与恢复参数在重放中固定，禁止用深采结果改变控制策略。

4.4 下压概率

用独立 RNG（由固定种子、局身份、轨迹类型、推理序号、样本序号确定）生成 32 份噪声。同一处的观测和记忆固定，不调用会推进真实策略 RNG 或记忆的接口。归一化动作经同一输出变换后得到物理关节动作，再在 official-sim 中计算目标 TCP 高度。真实 rollout 的那份噪声另记，不混入 32 份。报告 Wilson 区间；概率高低不直接证明模型知道正确时刻。

4.5 下压方向 d

delta = mean_noise(x0_normalized[press_infer, :, :16, :8])
      - mean_noise(x0_normalized[press_infer-1, :, :16, :8])
press_direction = delta / norm(delta)   # (16, 8)，保留逐行方向
对 32 维模型速度场仅取前 8 维；其余 24 维不参与归因

每份轨迹独立构造方向，不跨正常/延长轨迹混用。没有下压、没有前一点或差向量为零时，该方向及相应梯度/投影标为不适用并注明原因，不构造替代方向。

4.6 按 value 范数加权的注意力

主干 kv 头数为 1，V[l] 形状为 (b, P, 1, H)，8 个 query 头共用每 token 的 value 范数。weighted_attention = probs_action × ‖V[l][key]‖；只汇总前 16 个动作 query 并报告相对均匀的比值。它忽略向量方向、抵消和后续投影，只是加权注意力指标。

4.9 线性探针

  • 样本：深度集合内的推理，隐状态取各层帧记忆、motion、动作 token 的分组平均。
  • 目标：是否在合适开始下压范围内、已经过次数、距合适下压中心的步数。
  • 防错：按局做 5 折，同一个局的正常和延长轨迹必须同折；按局打乱标签作对照；同位置「只用当前图像 token」作对照；局级 bootstrap 给区间。
  • 限制：样本只在决策点附近，次数和时间高度相关。结论只写「可解码」，不写「模型使用了」。
