三、从窗口到 memory：哪些地方改数、哪些权重共享

代码锚点：representation/percep_mem.py::PerceptualMemory.__init__/__call__。每个模型只创建一份 motion_encoder_static；所有窗口、槽位和 batch 样本共用同一个 1280×1024 kernel 和 1024 bias。B 的 wan_flat_proj同样逐槽共享，不为 9 个时间槽建立 9 套参数。两者采用现有 representation/utils.py::kernel_init（std=0.02、bias=0）；B 不加第二个隐藏层或 SiLU。已有位置投影的 SiLU 保留。

padding 在原始特征一侧完成。A 输入 observation 为 (B,1280,512)，B 为 (B,1440,16384)；B 的 512 维由 JAX 模型实时生成。padding 过线性层可能变为非零，必须仍由 memory mask 屏蔽；不能靠“原输入是零”替代 mask，也不能把已训练的 B 投影输出写回离线固定表。

窗口时间与可见性：沿用 motion_store::visible_motion_rows。exec 在当前帧 t 只读取整个 33 帧已完成的窗口；demo 在 exec 开始后可见，尾段至少 17 个真实帧，其余只重复本段末帧。两个实验用完全相同的窗口 ID 集合，先按 160 窗补齐，再分别展开 8/9 槽，mask、窗口起点 PE 和时间键也 repeat8/repeat9。shared/sampling.py::memory_order按“全域时刻、帧先于 motion”的稳定排序一起重排 token 与 mask。

A 的 8 个 query 是学习得到的槽位，不是 8 个时间点。B 的 9 槽是 VAE 的有序时间 latent，各槽有时序感受野，也不是 9 张独立原图。本轮两组都沿用窗口起点时间码，B 槽内次序按 g=0…8 保留；不额外给 B 换成逐槽物理帧时间码。超过 160 窗就明确失败，不静默裁剪两组的历史。

四、memory modulation 完整展开

Cᵢ = Out(softmax(QᵢKᵀ/√256 + mask)V)
[γᵢ, βᵢ] = Dense(Cᵢ)
uᵢ = RMS(xᵢ) ⊙ (1+γᵢ) + βᵢ
yᵢ = xᵢ + gateffn(τ) ⊙ dropout(FFN(pre_ffw_norm(uᵢ,τ)))

xᵢ是本层 self-attention 残差后的动作状态；最后残差加回它。γ/β 是 memory 产生的 scale/shift，不是原 FFN residual gate。调制 Dense 的 std 为 0.002，与输入适配器的 0.02 区分；现实现是小随机初始化，不能宣称初始状态与无 memory 模型相同。

TRAIN_SMOKE_AB=PASS每臂原完整模型真实B1有效窗口一步更新；loss/梯度有限，内容投影及B Wan投影有非零梯度与实际更新，masked padding无有效贡献；旧768/pair4回归。新输入真实参与学习；不使用缩小模型或假张量替代。
