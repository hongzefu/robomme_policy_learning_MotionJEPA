第一部分（给人看）

一、要做什么（总览与已定口径）

PatternLock 先放一段示范：杆尖从起点格走到下一格。随后机械臂回到起点，要按同样的路线重走一遍。文字指令是固定的一句话，不含路径，所以往哪走只能从记忆里读。记忆里有两路：示范帧（frame memory）和示范 motion token。本计划只把示范段的 motion token 换成另一局（供体局）的，帧记忆、文字、seed 全部不动，然后看机械臂往哪走。

easy 档是 3×3 盘，格子编号 = 行 × 3 + 列（行增加为 +x，列增加为 +y，源码 PatternLock._load_scene）。motion 模型在官方 50 局里有 8 局只有 1 个子目标，全部成功。它们的示范只有 25–37 帧，正好只占 1 个 motion 窗口（起点为第 0 帧，窗长 33）。下表的路径是按每局 env_seed 用 _load_scene 的同一段随机数逻辑复算的，路径长度与 1106 记录的子目标数 m 逐局一致。

二、怎么换（机制）

定义：「位置」指示范第一步的起点格，「方向」指这一步的 8 邻方向。每次交换由一个接收局和一个供体局组成，接收局照常跑闭环 rollout，只有示范段那一个 motion 窗口的编码换成供体局同一窗口的编码。

锚点：不改模型和环境代码，直接用现有能力：

  • scripts/interpret/serve_policy_attn.py 的 --record-motion：把每局每个窗口的 (start_frame, emb) 写成 <task>_ep<id>.npz（run_local 收尾改名）。
  • 同文件的 motion_swap_exact:<DIR>：只替换起点在供体 start_frames 里精确存在的窗口，其余窗口保留本局原值。
  • scripts/interpret/run_local.py 的 swap_map（接收局 → 供体局）和 subgoal_trace（客户端逐步记杆尖位置，写 traces/<nonce>/step_trace.jsonl）。

只换示范窗口的做法：把供体 npz 裁到只剩 start_frame == 0 那一行，放进单独的供体目录。motion_swap_exact 遇到执行段窗口时在供体里查不到精确起点，就保留接收局原值。motion token 个数、位置、motion_mask、mem_order 都不动（该模式本身的保证）。

⚠ 陷阱：

  • 不能用 motion_swap:（非 exact）：它查不到起点时会退回供体的最近窗口，执行段 motion 也会被换掉。
  • 供体帧数不同（25–37）只影响供体自己的编码内容，不影响接收局的窗口起点，因为所有示范窗口都从第 0 帧开始。
  • 帧记忆没换，接收局的示范帧仍然显示自己的路线。所以结果读的是「motion token 和帧记忆冲突时，模型听谁的」，不是「只有 motion 时」。

三、配对（三种条件）

条件接收局 ← 供体局跟自己的示范会走到跟供体示范会走到次数
A 位置相同、方向相同5←28；28←55；55；5（两者相同）2
B 位置相同、方向不同20←5；5←20；28←200；5；55；0；03
C 位置不同、方向相同20←25；25←48；48←20（都向左）；29←32；32←29（都向上）0；3；1；4；0（照供体的相对方向走也是这些格）照供体的绝对目标格：3；1；0；0；45

A 是对照：5 和 28 路径相同，只是场景 seed 不同，交换后应该仍然成功。B 能看出方向是不是从 motion token 读的。C 能看出 token 记的是相对方向还是绝对位置：照相对方向走，会走到接收局自己的目标格；照绝对位置走，会走到供体的目标格。三个条件分三次运行（每次一个 swap_map），因为局 5、20 在两个条件里都当接收局。

四、读数与可能的结论

每次交换报：成功与否、杆尖第一次到达的非起点格、这一格与「自己目标 / 供体绝对目标」的对应、交换前后两个示范窗口编码的余弦距离。到达格的判据：执行段内杆尖水平位置与某个非起点按钮中心的距离第一次 < 0.025 m（环境 goal_thresh），按钮中心 x = −0.1 + (行 − 1) × 0.1、y = (列 − 1) × 0.1；全程都没到则记「未到」。

看到的结果能说什么不能说什么
A 全成功，B 改走供体方向单步时方向信息可由示范 motion token 决定，且压过帧记忆不能推到多步、其他任务或成功率
B 仍走自己的方向这几局里帧记忆或当前画面足以决定方向，换 motion 不改行为不能说 motion token 不含方向信息
C 走接收局自己的目标与「token 记相对方向」一致2 个方向、5 次交换，只是个例
C 走供体绝对目标或跑偏token 里也带了位置信息同上

每对只跑 1 局（seed 固定，XLA 确定性开启），10 次交换只是个例，不算成功率、不做区间。
