第一部分（给人看）

一、要做什么（总览与已定口径）

PatternLock 先放一段示范：杆尖从起点格走到下一格。随后机械臂回到起点，要按同样的路线重走一遍。文字指令是固定的一句话，不含路径，所以往哪走只能从记忆里读。记忆里有两路：示范帧（frame memory）和示范 motion token。本计划只把示范段的 motion token 换成另一局（供体局）的，或者置零；帧记忆、文字、seed 全部不动，然后看机械臂往哪走。

二、怎么换（机制）

定义：「位置」指示范第一步的起点格，「方向」指这一步的 8 邻方向。每次交换由一个接收局和一个供体局组成，接收局照常跑闭环 rollout，只有示范段那一个 motion 窗口的编码换成供体局同一窗口的编码。置零组把这一个窗口的编码换成全零向量。

锚点：不改模型和环境代码，直接用现有能力：

  • scripts/interpret/serve_policy_attn.py 的 --record-motion：把每局每个窗口的 (start_frame, emb) 写成 npz，run_local 收尾改名为 <task>_ep<id>.npz。
  • 同文件的 motion_swap_exact:<DIR>：只替换起点在供体 start_frames 里精确存在的窗口，其余窗口保留本局原值；供体文件由 load_donor 读 start_frames、embs 两个键。
  • scripts/interpret/run_local.py 的 swap_map（接收局 → 供体局，允许映射到自己；有 swap_map 时每块只跑 1 局）、model_seed（经 scripts/evaluation/resident_worker.py::server_command 以 --seed 传给服务端，决定采样噪声）、subgoal_trace（客户端逐步记杆尖位置，写 traces/<nonce>/step_trace.jsonl）。

只动示范窗口的做法：

  • 交换：把供体 npz 裁到只剩 start_frame == 0 那一行，放进 donor_trim/。执行段窗口在供体里查不到精确起点，保留接收局原值。
  • 置零：zero/PatternLock_ep<id>.npz 只有一行 start_frame = 0、emb = 0，swap_map 把每局映射到自己，同样走 motion_swap_exact。
  • 两种做法下，motion token 个数、位置、motion_mask、mem_order 都不动（该模式本身的保证）。

⚠ 陷阱：

  • 不能用 motion_swap:（非 exact）：它查不到起点时会退回供体的最近窗口，执行段 motion 也会被换掉。
  • 不能用现成的 motion_zero：它把所有窗口都置零，执行段也会被影响，和交换组不可比。
  • 帧记忆没换，接收局的示范帧仍然显示自己的路线。所以结果读的是「motion token 和帧记忆冲突时，模型听谁的」，不是「只有 motion 时」。
  • RECORD_REPRO 要求 seed 42 下 8 局全成功；当前 HEAD 比 1106 的执行版本 6994a59 新，不全成功就说明执行有差别，停下。

四、读数与能下的结论

每局读数：成功与否；杆尖第一次到达的非起点格；这一格属于「自己目标 / 供体绝对目标 / 其他格 / 未到」哪一类。到达格判据：执行段内杆尖水平位置与某个非起点按钮中心的距离第一次 < 0.025 m（环境 goal_thresh），按钮中心 x = −0.1 + (行 − 1) × 0.1、y = (列 − 1) × 0.1。另报每对交换前后两个示范窗口编码的余弦距离（与 Table 3 同口径）。

汇总：每组报上面四类各占几成（局数 / 总局数），并逐对列出 5 个 seed 中各类的局数。统计单位是局；每组只有 10–40 局，只报计数和比例，用局级重采样 2000 次给 95% 区间作参考，不做显著性检验。

问题看哪几组怎么判
Q1 这些局本身稳不稳NN 在 5 个 seed 下的成功率。它是 A/B/C/Z 的比较基线，偏低时其余组的失败要先扣掉它
Q2 方向是不是从 motion token 读的B 对比 N、ZB「走到供体目标格」的比例明显高于 N、Z 的同类比例（N、Z 里走到那一格只能是走错）。B 只是失败而不走到供体格，就和 Z 一样，只说明扰动有影响
Q3 换 token 本身会不会打乱它A、Z 对比 NA 应接近 N（同方向同位置换了也没事）。Z 明显低于 N，说明示范 motion 窗口确实被用到
Q4 token 记的是相对方向还是绝对位置C 对比 N、Z，并结合 Q2只有 Q2 成立（模型会跟 token 的方向）时 C 才可解读：C 接近 N，说明 token 记相对方向；C 走到供体绝对目标格的比例高，说明 token 带位置信息；C 只是失败、接近 Z，说不清。Q2 不成立时，C 成功也可能只是模型没用 token，因为照相对方向走到的正好是帧记忆指向的格

能说与不能说：结论只覆盖 easy 档单步、motion 模型、这 8 局。B 只有起点格 1、两个方向；C 只有向左、向上；A 只有 5↔28 一对。不推到多步、其他任务和基线模型。
