评估侧做什么

在 test 布局（官方 test metadata 追加 xhard 五档 624 条 seed）上，用同一份 1200 局清单评三个模型：自训 512 run @60000、自训 512+motion run @60000、官方 FrameSamp modul 79999。全部在 GreatLakes 单卡 A40 上执行，12 个占位 job，正式 30 个单元按 512 → 512+motion → 官方顺序领取。
