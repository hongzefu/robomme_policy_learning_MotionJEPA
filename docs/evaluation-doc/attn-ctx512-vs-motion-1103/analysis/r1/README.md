## 一句话结论
**没有读到。** 把 prefill 内部的间接通路算进来以后，基线的记忆区有效质量确实变大了（#18 帧流从直接 attention 的 0.9% 涨到 8.4%），但多出来的质量几乎都落在**最近一帧附近的单个 sink token** 上（#15～#19 rollout 帧流最大帧占 21～31%，其中 51～98% 来自该帧的一个 token）。VIS 的有效占比反而更低：#15～#19 平均从直接的 7.0% 降到 1.7%，均匀期望是 13.1%。去掉每帧最大的 token 再算也只有 6.2%，仍然低于均匀。SWAP 同样低于均匀（基线 ep8 rollout 13.0%，均匀 35.6%）。只走记忆区内部混合的那条通路，VIS 是 6.0%，同样低于均匀。所以「只看最近帧」不能解释成「通过记忆区内部间接看了 VIS／SWAP」。motion 模型的记忆区内部通路 VIS 有 21.0%，高于均匀 13.1%。

## 1. 口径与假设
- **有效位置**：取记忆区中 `mem_mask` 为真的位置、当前图像 512 个位置，以及前 `txt_len` 个文本位。padding 的行和列都剔除（prefix 里 padding query 行全是 0，基线每层 45 行，motion 每层 132 行）。
- **每层图**：先对 8 个头取平均，得到 `probs_prefix_l[V,V]`，行归一后得到 A_l。令 Ã_l = 0.5·A_l + 0.5·I，再做一次行归一。递推为 R_0 = I、R_{l+1} = Ã_l·R_l。R_l[k,j] 表示第 l 层输入在位置 k 上，对原始输入 token j 的近似贡献。
- **动作有效贡献**：动作在第 l 层读的是 prefill 第 l 层的 KV，也就是第 l 层的输入表示。所以 c_l[j] = Σ_k a_l[k]·R_l[k,j]，其中 a_l 是第 l 层动作 query 对 prefix 的 attention，在 10 个去噪步、20 个动作 query、8 个头上取平均。最终的 c 是 18 层的平均（逐层 c_l 也保存在 json 的 `layers` 里）。动作对动作 key 的质量原样留在 action 流，因此 c 的总和仍为 1。
- **直接版** d = 18 层平均的 a_l，与 `split_streams` 的全层全头平均一致。
- **联合 rollout（补充）**：把 20 个动作 token 也放进图中。第 l 层的动作行为 0.5·[a_l 对 prefix, a_l 对动作] + 0.5·I。取第 18 层后 20 个动作行的平均，这样能包含「动作→动作→prefix」的路径。
- **中介分解（对照）**：把 c_l[j] 按中介 k 的类别拆成三份：经记忆区、经当前图像、经文本。记忆区的行只看记忆区（实测记忆区行对图像加文本的质量为 0），子块在乘法下封闭，因此「经记忆区」这一份就是「只用记忆区子块做的 rollout」。
- **去 sink 对照**（与 X4 同口径）：每帧剔除帧内最大的单个 token 后，重算帧流的 VIS／SWAP 占比，均匀期望不变。
- **假设与近似**：① 残差按 0.5 恒等近似，实际残差与注意力输出的范数比未知；② 忽略 MLP 与 LayerNorm 的混合；③ 头平均，丢掉了头间差异；④ 没有用值向量范数加权（attention 质量不等于信息量）；⑤ 去噪步与 query 都取平均。rollout 是对「信息可能从哪里来」的上界式估计，不是因果贡献。
- **实测可见关系的补充**：当前图像确实看不到记忆区（18 层的 img→mem 都是 0），但**能看文本**（img→txt 每层 7～75%）。文本在第 0、1 层把大量 attention 给记忆区（基线 ep8 #18 为 72%／17%，motion 为 60%／56%），后面各层 ≤5%。所以图像存在「图像→文本→记忆区」的两跳通路，这正是下面「经图像中介」的质量来源。

## 2. 直接 attention 与 rollout 对比（fig_r1_1、fig_r1_2）
帧流占比（占帧流的百分比；#15～#19 平均，括号里是 #18）：

| 局 | VIS 直接 | VIS rollout | VIS 联合 | VIS rollout 去 sink | VIS 均匀 | SWAP 直接 | SWAP rollout | SWAP rollout 去 sink | SWAP 均匀 |
|---|---|---|---|---|---|---|---|---|---|
| 基线 ep8 | 7.0（3.6） | 1.7（1.8） | 2.3（2.8） | 6.2（5.8） | 13.1（12.5） | 22.7（13.5） | 13.0（12.0） | 25.0（22.4） | 35.6（34.4） |
| 基线 ep4 | 6.7（5.2） | 1.8（1.5） | 2.3（2.4） | 6.5（5.6） | 13.1（12.5） | 11.2（7.0） | 4.1（2.8） | 4.1（5.3） | 17.5（18.8） |
| motion ep8 | 17.2（17.0） | 5.9（4.6） | 9.2（7.0） | 14.0（20.7） | 13.1（12.5） | 33.8（30.6） | 6.5（4.7） | 14.6（20.0） | 35.6（34.4） |

- **记忆区有效质量放大约 7～10 倍**：基线 ep8 #18 的帧流从直接的 0.9% 变成 rollout 的 8.4%；#15～#19 三局 rollout 的记忆区质量为 5～10%，直接 attention 只有 0.2～2.2%。
- **放大的质量去了 sink**：#15～#19 rollout 帧流的最大帧都是近期帧。基线 ep8 为 t=224/239/254/278/284，占帧流 30.7/27.4/25.7/21.5/21.5%，该帧最大单 token 占 94.0/51.2/86.1/89.3/56.2%。基线 ep4 为 t=224/239/254/269/294，占 30.9～20.2%，单 token 占 84.4～98.3%。motion ep8 为 t=232/247/263/278/294，占 68.2/76.9/79.9/78.2/63.5%，单 token 占 51.1～98.6%。fig_r1_2 里基线 #18 的 rollout 在 t=269、278 各约 21%，motion 的 t=278 达 78%。直接 attention 里基线的最大帧是 t=288（当前步那一帧），占帧流 64%。
- **去 sink 后基线仍低于均匀**：VIS 为 6.2%／6.5%，均匀 13.1%，和直接 attention（7.0%／6.7%）差不多，没有出现隐藏的 VIS 读取。motion 模型去 sink 后 VIS 为 14.0%，约等于均匀；直接 attention 的 17.2% 是 1.3 倍均匀。
- **整局曲线**：早期 #5～#10 基线两局在 SWAP1 帧上的偏好，rollout 下保持不变（SWAP1 帧流占比：基线 ep8 直接 58.3%、rollout 58.9%；ep4 为 56.7%、57.4%；均匀 33.9%）。这一阶段的 sink 帧本身就在 SWAP1 内（例如 #7 的 sink 在 t=104），去 sink 后基线 ep8 #5～#10 的 SWAP 仍有 38.8～89.9%，所以早期对第 1 次交换帧的偏好在 rollout 下也成立。#11 之后各条曲线回落到均匀以下。motion 模型 #5～#10 的 rollout VIS 为 14.6%，低于直接的 38.9%（均匀 28.6%）。
- **motion 流（motion ep8）**：rollout 后 motion 流的总质量从 0.3% 涨到 2.0%（#18）。#18 VIS 窗计权从直接的 8.2% 变为 rollout 的 4.3%（均匀 10.8%），SWAP 从 30.5% 变为 22.3%（均匀 35.0%）。两种算法都没有高于均匀。
- 联合 rollout（含动作→动作路径）与层平均 rollout 的结论一致，数值略高（例如 motion VIS 9.2% 对 5.9%）。

## 3. 间接通路主要走哪类 token（fig_r1_3、fig_r1_5）
#15～#19 平均，rollout 落在记忆区的质量（占动作 attention 的百分比）及其帧流 VIS／SWAP 占比：

| 局 | 经记忆区：质量 | 经文本：质量 | 经图像：质量 | 经记忆区：VIS／SWAP | 经文本：VIS／SWAP | 经图像：VIS／SWAP | 均匀 VIS／SWAP |
|---|---|---|---|---|---|---|---|
| 基线 ep8 | 0.59 | 3.05 | 3.02 | 6.0／28.7 | 1.5／11.8 | 1.1／11.5 | 13.1／35.6 |
| 基线 ep4 | 0.62 | 2.98 | 3.03 | 6.0／12.1 | 1.5／3.4 | 1.2／3.2 | 13.1／17.5 |
| motion ep8 | 1.90 | 3.28 | 2.98 | 21.0／25.9 | 3.4／3.5 | 3.4／2.9 | 13.1／35.6 |

- **间接质量大部分走文本或图像（图像→文本→记忆）**：基线约 91%，motion 约 77%。其余部分是「动作直接读记忆 token，再由记忆区内部混合」。motion 模型经记忆区的份额更大（1.90 对 0.6）。
- 经文本或图像过来的质量几乎全落在 sink 帧上，VIS 只占 1.1～3.4%。
- **只用记忆区子块（经记忆区）**：基线两局 VIS 为 6.0%，低于均匀 13.1%，与直接 attention 持平；motion ep8 为 21.0%，是均匀的 1.6 倍，高于直接 attention 的 17.2%。也就是说，motion 模型的记忆区内部混合确实把 VIS 信息往动作可读的位置汇集，基线没有。
- **末层记忆区 R 的形态**（fig_r1_5，#18）：18 层之后，记忆区各位置的来源分布几乎相同（行间无差别，帧级对角均值 0.031，正好等于 1/32），是典型的 rollout 过平滑。基线 ep8 的来源集中在 t≈176～185 与最近几帧，VIS 4 帧合计约 5.2%（均匀 12.5%）；ep4 类似，约 5.3%。motion ep8 的帧 token 行有 **59.8% 的质量落到仅 9 个有效 motion token 上**，motion token 在记忆区内部充当汇聚点。剩余帧部分里 VIS 约 18%，高于均匀。

## 4. 逐层（fig_r1_4，#18）
- 直接 a_l 的帧流质量集中在第 15 层：基线 ep8 为该层动作 attention 的 10.3%，ep4 为 8.5%。这一层的 VIS 只有 0.2～0.3%，几乎全给当前步那一帧，「只看最近帧」主要来自这一层。motion ep8 的帧流质量峰值在第 16 层（7.1%），VIS 为 22%。
- rollout 的 c_l 从第 1 层起 VIS 就只有 0.2～2%，说明早层文本→记忆的 sink 已经决定了大部分有效来源。往后 VIS 缓慢回升到 3～4%（基线）和 7～11%（motion）。

## 关键发现
1. 基线「只看最近帧」**没有**借 prefill 间接读到 VIS／SWAP。#15～#19 rollout 的 VIS 为 1.7%／1.8%，去 sink 后 6.2%／6.5%，都低于均匀 13.1%；SWAP（基线 ep8）为 13.0%，去 sink 25.0%，低于均匀 35.6%。
2. 间接通路把记忆区的有效质量放大 7～10 倍（#18 基线 ep8：0.9% → 8.4%），但大部分（基线约 91%，motion 约 77%）经文本或图像中介，并落到近期帧的单个 sink token 上（单 token 占该帧 51～98%）。这属于位置性的 sink，不是内容检索。
3. 只走记忆区内部混合的那部分，基线 VIS 是 6.0%（低于均匀），motion 模型是 21.0%（1.6 倍均匀）。motion 模型对 VIS 的偏好在记忆区内部通路上依然存在，而且比直接 attention 更强。
4. 早期 #5～#10 基线对第 1 次交换帧的偏好在 rollout 下保持（SWAP1 58.9% 对均匀 33.9%）。基线确实「看过」交换，只是在 #15～#19 抬起阶段不再回看。
5. motion 模型记忆区的帧 token 末层有约 60% 的 rollout 来源是 9 个 motion token。motion token 在记忆区内部是汇聚点，但动作端最终读到的 motion 流仍不高于均匀（#18 SWAP 22.3% 对 35.0%）。

## 局限
- 只有 3 局（2 局 ep8 成功、1 局 ep4 失败），单 seed；attention 与 rollout 都不是因果贡献，没有做消融或梯度归因。
- rollout 的 0.5 残差、忽略 MLP、头平均、不按值范数加权都是近似。多层连乘会过平滑（末层记忆区 R 行间几乎相同），而且会放大 sink。所以「rollout 占比低」只能说明「按这一近似没有看到间接读取」，不能证明信息完全没有经过别的通道传递，例如 MLP 或残差流中非 attention 的部分。
- 去 sink 只剔除每帧最大的一个 token，与 X4 相同，是粗粒度的稳健性对照。
- 分段占比都是帧流或 motion 流内部的比例。rollout 记忆区总质量只有 5～10%，主体仍是当前图像（24～39%）、文本（23～39%）和动作自身。
