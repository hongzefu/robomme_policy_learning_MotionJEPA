# R4：逐层通路，动作读取 VIS／SWAP 是直接读还是经中转 token 读

## 问题

记忆里关于裸露窗 VIS=[0,32) 和交换区间 SWAP1=[64,114)、SWAP2=[114,164) 的信息，在哪几层、经由哪条通路流向动作 token？本节逐层分解，与 R1 的全局 rollout 互补：R1 把所有层的注意力连乘后取均值，本节不连乘，看每一层各走了哪条路。

## 数据

三局 stage1b 重跑数据（只读，与上一轮逐位一致），每局 20 次推理，同时有 `infer_*.npz`（动作 query 的注意力）和 `prefix_*.npz`（prefill 时 prefix 内部完整注意力 (18 层, 8 头, P, P)）：

| 标签 | 局 | k（交换次数） | 目录 nonce |
|---|---|---|---|
| base_ep8 | ctx512 基线 ep8，成功 | 2 | `0621439bab554595b3ee0f0f9414ba84` |
| base_ep4 | ctx512 基线 ep4，失败 | 1 | `3a79ca2d563c4a679d51013e15394130` |
| mot_ep8 | ctx512+motion ep8，成功 | 2 | `afb7438311e44dfab40a03e709c2ab16` |

关键推理是 #18（step 288，「揭开」）；#15、#16 在它前面，#17 夹爪下降闭合，#19 是抬起之后。

## 通路定义

prefix 的排布是 [记忆区 | 当前图像 512 | 文本 64]，后面接 20 个动作 token。

- **目标权重 g_T(s)**：帧 token 的时刻落在 T 内记 1，否则记 0；motion token（窗起点 t_w，长 33）记 |[t_w, t_w+33) ∩ T| / 33；其他 token 记 0。另加一个目标 SWAP = [64, 64+50k)，即各次交换区间的并集。
- **动作读取 a_l**：第 l 层 `probs_action` 在 10 个去噪步、20 个动作 query、8 个头上取平均，和 `aggregate_attn.aggregate(layers=l)` 是同一口径。脚本逐层把 a_l 交给 `split_streams` 分流，断言帧流质量一致。
- **直接** D_l(T) = Σ_s a_l[s]·g_T(s)，拆成帧流部分和 motion 流部分。
- **一跳间接** I_l(T) = Σ_k a_l[k]·(1−g_T(k))·R_{<l}[k,T]。其中 R_{<l}[k,T] = (1/l)·Σ_{m=0}^{l−1} B_m[k,:]·g_T，B_m 是第 m 层 prefix 注意力的头平均。k 是动作 token 时，B_m 换成同一去噪步、第 m 层动作 query k 的读取，按步、按 query 配对后再平均。
  - 为什么取「第 0～l−1 层的均值」，而不是只取第 l−1 层：残差流会把 k 在更早任意一层读到的东西保留到第 l 层的输入。只取 l−1 层，会漏掉「浅层读进来、深层再被读走」的通路。取均值而不是求和，是为了让 R 留在 [0,1] 内，和直接质量的量纲一致。
  - 只取第 l−1 层的口径作为敏感性对照输出（`ind_adj`）。#18 各层求和后两种口径量级一致：motion VIS 0.0434 对 0.0372，基线 ep8 VIS 0.0085 对 0.0064。差别主要在 L17。
- **两跳**（只给总量，相邻层口径）：Σ_k Σ_j a_l[k](1−g(k))·B_{l−1}[k,j](1−g(j))·B_{l−2}[j,T]。
- **中转类别**：
  - 最近帧：时刻最晚的 4 个有效帧，#18 时是 t=260～288；
  - 中段帧：其余非目标帧，包括另一个区间的帧；
  - motion 窗；
  - 当前图像：按掩码看不到记忆，所以一跳间接恒为 0。实测图像→记忆的最大注意力质量为 0.0，作为掩码自检；
  - 文本；
  - 动作 token。
- **均匀期望**：假设同一行注意力在帧流内均匀分配、在 motion 流内也均匀分配，算它落在 T 上的质量，即 E = 帧流质量·n_T帧/n帧 + motion 流质量·mean_w g_T(w)。直接和间接各自算 E，倍数 = 实测 / E。
- **近似假设**：这里只看 attention，忽略 MLP、残差强度和 value 向量范数；头平均会抹平单头的差异。所以「质量」只是信息通路的上界式代理，不是因果贡献。

## 口径自检

- 全层平均的 #18 帧流 VIS 占比：基线 ep8 **0.0357**，motion ep8 **0.1705**，与上一轮 KEY_STEP（0.0357／0.1705）一致。基线 ep4 为 0.0516。
- 18 层逐层 `split_streams` 交叉核对全部通过（误差 < 1e-6）。图像行对记忆的注意力为 0。

## 关键数字

下文「各层求和」指 18 层的 D_l 或 I_l 相加；「层均」指它们的平均。

**1. motion 模型把 VIS 信息带给动作的总量约是基线的 5～8 倍，而且直接和间接两条路都更多。** #18 各层求和：

| 局 | VIS 直接 | VIS 一跳间接 | SWAP 直接 | SWAP 一跳间接 |
|---|---|---|---|---|
| motion ep8 | 0.0454 | 0.0434 | 0.0891 | 0.0838 |
| 基线 ep8 | 0.0058 | 0.0085 | 0.0217 | 0.0495 |
| 基线 ep4 | 0.0070 | 0.0089 | 0.0095 | 0.0141 |

相对均匀期望的倍数（层均）：

- VIS 直接：motion 1.28×，基线 ep8 0.29×，基线 ep4 0.41×；
- VIS 间接：motion 0.50×，基线 ep8 0.12×，基线 ep4 0.16×。

**2. motion 模型的 VIS 主要在 L3 和 L16 被直接读取，正是上一轮找到的 VIS 头所在层。** #18：

- L16 直接 0.0165（约 3.3 倍于间接 0.0050），富集 1.71×，其中帧流 0.0158、motion 流 0.0007；
- L3 直接 0.0088，富集 **2.83×**，其中 motion 流贡献 0.0011，是全部层里最大的 motion 流直接 VIS；
- L3 之后紧接着在 L4 出现最大的经文本间接（0.0034，占 L4 间接 0.0055 的 62%）。这与「文本 token 在 0～3 层读过 VIS，L4 的动作 query 再从文本把它取走」一致（attention-only 推测）。这是一条浅层的「记忆 → 文本 → 动作」通路，基线里几乎没有：基线 ep8 L4 经文本只有 0.00002。
- L14～L16 的间接主要走中段帧（0.0024、0.0019、0.0028）：记忆区内部双向注意力里，中段帧先读过 VIS，深层动作再读中段帧。
- 逐推理看，L3 直接 VIS 的富集从 #3 起总体上升（#10～#12 有回落），到 #16 约 3×，#15～#19 实测为 2.31×／3.11×／2.83×／2.83×／2.57×（`cell_stats.mot_ep8.vis_direct_L3_by_infer`；见 `fig_r4_key_layers_curves.png`）。

**3. 基线 #18 最大的 VIS「通路」其实是 L15 经最近帧的间接，而且是被稀释过的。** 基线 ep8 L15：

- 直接 VIS 只有 0.00025，富集 0.02×，因为 L15H1 几乎只看最近 4 帧；
- 但经最近帧的间接有 0.0041，占 L15 间接 0.0044 的 92%，两跳也是 0.0092。也就是说，基线动作读的「最近帧」表征里混有一点 VIS 信息，但富集只有 0.33×，低于均匀。
- 基线 0～7 层的直接 VIS 富集是 1.1～2.3×，数量却都 ≤ 0.0008。

**4. 基线成功局 ep8 与失败局 ep4 在 #14～#17 的逐层通路基本重合。**

- VIS 直接逐层曲线在 L0～L14 几乎重叠。差别只在 L16：ep4 是 0.0029，ep8 是 0.0009，失败局反而更多。
- VIS 间接在 L15～L16 也是 ep4 更高（0.0019／0.0020 对 0.0009／0.0009）。
- SWAP1 直接在 L16 两局都约 0.005～0.006；SWAP1 间接在 L15～L16 是 ep4 高（0.0045／0.0047 对 0.0030／0.0029）。注意 SWAP1 是 ep4 唯一的一次交换，但只是 ep8 两次交换里的第一次。
- 层均富集 #14～#17：VIS 直接 ep8 0.64× 对 ep4 0.59×，VIS 间接 0.19× 对 0.24×。
- 从这对局里找不到「失败局少读了 VIS／SWAP」的逐层证据。这与 X1 的头结构结论一致（单对观察）。

**5. SWAP 信息早期主要经文本中转，后期衰减。**

- 整局层均里，基线 ep8 SWAP 一跳间接 0.0086，其中经文本 0.0073，占 84%，整体富集约 1.01×；
- 到 #18 时，基线经文本只剩 0.0015，间接富集降到 0.26×；
- motion ep8 #18 的 SWAP 间接改以中段帧为主（层均 0.0017，经文本 0.0016），L16 间接 0.0152，主要走中段帧（0.0095）。

**6. 一跳间接整体都低于均匀期望。** 热图（`fig_r4_vis_heat_layer_infer.png`）里间接 VIS 大多是蓝色。下面的格级统计来自 `r4_summary.json` 的 `cell_stats`：每个格是一个 (推理, 层)，取推理 #2～#19，排除帧流均匀期望平凡的 #0、#1；L1～L13 共 234 格。

| 局 | 中位数 | P25～P75 | P10～P90 | < 1/8× 的格 | ≥ 1× 的格 | 最大 |
|---|---|---|---|---|---|---|
| 基线 ep8 | 0.17× | 0.07～0.31× | 0.04～0.54× | 41% | 5% | 1.03× |
| 基线 ep4 | 0.20× | 0.07～0.32× | 0.04～0.57× | 38% | 4% | 1.03× |
| motion ep8 | 0.51× | 0.37～0.66× | 0.22～0.79× | 7% | 6% | 1.03× |

扩到 L1～L17 共 306 格：基线 ep8 中位数 0.24×、31% 的格 < 1/8×；motion 中位数 0.56×，最大 1.16×。

也就是说，在 attention-only 口径下，中转 token（文本、记忆帧）本身并不偏好去读 VIS。motion 模型的优势看起来主要来自 L3／L16 的直接读取，以及更多中转 token 携带了 VIS 信息，而不是出现了富集的中转专线（未经消融验证）。

## 结论

1. motion 模型 #18 的 VIS 信息有一半左右（0.045／0.089）由动作 query 直接读取，集中在 L3（富集 2.8×）和 L16（质量最大，0.0165），与 X1 的 L3H0／L16H0 对应。另一半经文本（L4）和中段帧（L14～L16）间接到达。
2. 基线到达动作的 VIS 总量只有 motion 的 1/5～1/8。其中最大的一股是 L15 经最近帧的稀释间接通路，直接读取在任何层都很弱。
3. 基线成功局与失败局在 #14～#17 的逐层直接／间接通路几乎一样。成败差别看不出来源于「VIS／SWAP 在哪一层、经哪条路被读到」。
4. 两种中转定义（第 0～l−1 层均值，或只取 l−1 层）给出同量级的结论。

## 局限

- 只看 attention，没有 MLP、残差范数和 value 向量，质量不等于信息量或因果贡献；头平均会掩盖单头通路。要做因果结论，需要 ablation 或 patching。
- 一跳、两跳都把 attention 质量当成可传递量相乘，是线性近似。两跳只算了相邻层，也没有把动作 token 作为中间跳。
- 「最近帧」固定取 4 帧，「中段帧」包含另一区间的帧，类别边界是人为划分。
- 只有三局，基线成败对比是单对观察。
