# X2 整局时间线：模型何时开始、何时停止回看裸露窗与交换区间

## 问题

ButtonUnmaskSwap 一局的 20 次推理（step 0, 16, …, 304）里，模型从什么时候开始、到什么时候停止回看两个区间：裸露窗 VIS=[0,32) 和交换区间 SWAP=[64,64+50k)。成功局和失败局在回看上有什么不同？

比较三局：

| 局 | 结果 | 交换次数 k | SWAP 区间 | 有无 sim_eef_pose |
|---|---|---|---|---|
| 基线 ctx512 ep4 | 失败 | 1 | [64,114) | 无 |
| 基线 ctx512 ep8 | 成功 | 2 | [64,114)、[114,164) | 有 |
| ctx512+motion ep8 | 成功 | 2 | [64,114)、[114,164) | 有 |

## 做法

- 入口：`scripts/interpret/analysis/x2_timeline.py`。分流直接 import `scripts/interpret/aggregate_attn.py::split_streams`（没有改它）：动作 query，把 10 个去噪步、18 层、8 头和 20 个 query 全部平均。每次推理都通过了 pad ≤ 1e-6、五流之和 = 1 ± 1e-4 两项断言。
- 帧流占比：某个区间内采样帧的注意力质量 ÷ 帧流总质量。均匀期望 = 区间内采样帧数 ÷ 有效采样帧数，会随推理变化，因为 32 帧在 0…step_idx 上重采样。ep4 的 k=1，只有第 1 段 SWAP，所以三局的均匀期望各不相同，曲线图里都画在各自的面板上。
- motion 流 SWAP 占比：每个窗口按 [t, t+33) 与 SWAP 并集的重叠帧数 ÷ 33 加权，均匀期望 = 权重之和 ÷ 有效窗口数。
- 阶段由 state[7]（手指开度，< 3 cm 记为闭合）和 actions[:,7]（1 开，−1 闭）推出，规则是：首次闭合之前记「靠近按钮」，首次闭合到重新张开之前记「按按钮」，张开后指令全为 +1 记「张开靠近」，张开后出现 −1 指令记「下降闭合」，再次闭合记「抬起」。ep8 两局另外叠画 sim_eef_pose.json 里的 TCP z；ep4 没有 z。
- 热图：每个采样帧的格子从它的帧号一直填到下一个采样帧之前，最后一帧填宽取该行中位间距。motion 窗按起点画，宽 33。全部用 `imshow(interpolation="nearest")`。真实质量版三局共用一条对数色标；排名版在每行内做排名归一化（论文 arXiv 2610.14406 Figure 9 的画法，紫色最低、红色最高）。

## 关键数字（按阶段平均，记作「占比／均匀期望，比值 r」）

| 阶段 | 基线 ep4（失败） | 基线 ep8（成功） | motion ep8（成功） |
|---|---|---|---|
| 按按钮 #4–13，VIS | 0.112／0.275，r=0.41 | 0.116／0.275，r=0.42 | 0.361／0.275，r=1.31 |
| 按按钮，帧流 SWAP 第 1 段 | 0.451／0.281，r=1.60 | 0.490／0.281，r=1.74 | 0.247／0.281，r=0.88 |
| 按按钮，帧流 SWAP 第 2 段 | — | 0.091／0.229，r=0.40 | 0.209／0.229，r=0.91 |
| 张开靠近，VIS | 0.086／0.141，r=0.61（#14–17） | 0.121／0.146，r=0.83（#14–16） | 0.178／0.146，r=1.22（#14–16） |
| 张开靠近，帧流 SWAP 第 1 段 | **0.145／0.188，r=0.77** | **0.246／0.198，r=1.24** | 0.178／0.198，r=0.90 |
| 下降闭合 + 抬起，VIS | 0.047／0.125，r≈0.37（#18–19） | 0.041／0.125，r≈0.32（#17–19） | 0.165／0.125，r≈1.32（#17–19） |

| motion 流 SWAP 并集（按按钮 → 张开 → 下降 → 抬起） | — | — | r=0.83 → 0.74 → 0.71 → 1.03 |
| 帧流总质量（按按钮阶段均值） | 0.0073 | 0.0074 | 0.0216 |

帧流占比高于均匀期望的推理（r > 1）：

- 基线 ep4：VIS 一次都没有；SWAP 第 1 段在 #4–16 之间（#7、#14、#15 除外）。
- 基线 ep8：VIS 一次都没有；SWAP 第 1 段在 #4–16 之间（只有 #8 除外）；SWAP 第 2 段只有 #10。
- motion ep8：VIS 在 #2–19 几乎每次都高于均匀期望（只有 #6、#15 例外）；帧流 SWAP 两段基本贴着均匀期望；motion 流 SWAP 高于均匀期望的是 #4、5、10、11、16、19。

## 结论

1. **基线从不回看裸露窗。** 两局基线从 #4（step 64，开始按按钮）起，VIS 占比就降到均匀期望的约 0.3～0.9 倍，始终低于 1，成功局和失败局一样。也就是说，成败两局都未回看裸露窗（关联观察，非因果）。
2. **基线的「回看 SWAP」主要是近因偏好。** #4–13 期间，SWAP 第 1 段 [64,114) 正好是最近的那批帧，占比达到均匀期望的 1.6～1.7 倍（峰值是 #6 的 0.80／0.34）。#8 之后第 2 段 [114,164) 也进了记忆，但成功的 ep8 对它的平均比值只有 0.40，唯一一次超过均匀期望是 #10（0.309／0.281）。行内排名热图里，每行最红的格子都贴着对角线（最新帧）。
3. **失败局和成功局的差别出现在「张开靠近」阶段，比关键推理更早。** #14–16 里，成功的 ep8 仍把 SWAP 第 1 段维持在均匀期望之上（r=1.24，三次分别是 0.251、0.246、0.241）；失败的 ep4 在 #14 就降到均匀期望以下（r=0.77，#14–17 四次分别是 0.141、0.089、0.206、0.144）。到了下降闭合与抬起阶段（#17–19），两局对两个区间都低于均匀期望（r 在 0.26～0.71 之间），差别也随之消失。这只是三局里的一个关联，不能当作因果。
4. **motion 模型的帧流注意力明显更均匀，而且整局都偏向裸露窗。** 它在 #2–19 几乎每次 VIS 都高于均匀期望（按按钮阶段 r=1.31，下降与抬起阶段 r≈1.32，关键推理 #18 是 0.170／0.125）。帧流总质量约为基线的 3 倍（0.0216 对 0.0074），帧流 SWAP 两段都贴着均匀期望（r 在 0.88～1.0 之间）。行内排名热图里，#15–19 最红的格子集中在帧 0–30，而不是最新帧。
5. **motion 流的 SWAP 回看是间歇性的。** 并集占比整体低于均匀期望（r 在 0.71～0.83 之间），只在 #10–11（0.772／0.606、0.684／0.606）、#16（0.478／0.394）和 #19（0.362／0.350）冒尖。真实质量热图里最亮的窗口是 #13–16 的起点 160 窗（跨在 SWAP 第 2 段末尾及其后），不在 SWAP 段内部。
6. **帧流与 motion 流在注意力总量里只占很小一部分。** 五流堆叠图显示，动作 query 的质量里，文本占 22%–42%，wrist 图占 22%–37%，动作 token 占 28%–34%，base 图占 5%–15%；帧流只占 ≤ 3.3%（基线 ≤ 1.2%），motion 流 ≤ 0.9%。前面所有「占比」都是在这一小块记忆内部做的相对比较。

## 局限

- 只有三局，而且基线的成败对比（ep4 对 ep8）混入了不同的 episode、不同的 k 和不同的 SWAP 区间，均匀期望也不同。motion 只有一局成功局，没有 motion 的失败局可以对照。所有结论都只是相关观察，不是因果，也没有做显著性检验。
- 口径是动作 query 对全部层、头、去噪步取平均，个别层或个别头的回看行为可能被平均掉了。注意力质量也不等于这段信息被模型用上了。
- 阶段是按夹爪开度与指令的规则推出来的。ep4 没有 TCP z，阶段边界只能依据夹爪；motion ep8 的 #18 被判为「下降闭合」，与基线 ep8 的「抬起」差了一次推理。
- 热图里采样帧的格子宽度只表示时间上的覆盖，不是注意力密度。越早的帧采样越稀疏，所以格子越宽。
