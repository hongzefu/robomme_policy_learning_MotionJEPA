# MoveCube 强推恢复实验结果

## 一句话结论

两个模型都只在被带偏的早期还能回来：强推 16 步后抓取成功率降到约六到七成；一旦机械臂被带到错误物体附近（32 步起，水平距离 4 cm 以内），两模型几乎都直接下降抓错误物体（方向 A 0/21，方向 B 至多 1/12）。motion 模型与无 motion 基线在任一点位都没有可分辨的差异（同局配对精确 McNemar 全部 p=1.0）。

## 失败是怎么失败的

- 32 步及以后放手的失败局，绝大多数是直接抓了正下方的错误物体并被环境判负。按局末位置事后核对（错误物体 z>0.05 视为被抓起，这是近似读法）：方向 A 167 局里 163 局、方向 B 81 局里 68 局属于此类；从放手到判负的中位数只有 48 步（A）和 58 步（B）。
- 同样在 32 步以后，放手后 TCP 离正确物体的水平最小距离中位数为 0.24～0.27 m（A）和 0.16～0.23 m（B），说明这些局基本没有往回走。
- 强推 16 步时的失败局较分散：A 有 3～4 局判负、1～2 局超时；B 有 2 局判负、2～3 局超时，方向 B 失败局放手后中位数走了 864 步才结束，属于犹豫或卡住。
- 冒烟录像截帧（`records/smoke_sheet.png`）与上述一致：k=48 放手帧腕部相机正对错误物体，末帧方向 A 停在 peg 上、方向 B 的 cube 已在爪中。

## 两个模型的对比

| 方向 | k | 同局配对：都抓起 / 仅 motion / 仅基线 | p |
|---|---:|---|---:|
| A | 16 | 14 / 2 / 2 | 1.0 |
| B | 0 | 11 / 0 / 1 | 1.0 |
| B | 16 | 7 / 0 / 1 | 1.0 |
| B | 48 | 0 / 0 / 1 | 1.0 |

其余点位两模型逐局结局相同（全成功或全失败）。只有方向 A 的 k=16 出现双向不一致，各 2 局，没有一个模型更能恢复的迹象。

## 范围与限制

- 成功判据放宽为抓起正确物体（`is_obj_pickup`），不要求完成任务；去掉了 `gripper_push` 17 局。
- 强推从开局开始，只走到目标上方 z=0.2，不下降；k=64、80 多数局是到达后原地悬停再放手。
- 方向 B 只有 12 局，k=0 时 motion 有 1 局抓错；样本小，只能看大趋势。
- 单一模型 seed 42、每局一次采样；没有与目标无关的位移对照，因此不能区分「被拉向错误物体」与「任何同等位移」的影响。
- 「抓起错误物体」的分类是按局末位置的事后读法，不是环境给出的失败原因字段。
